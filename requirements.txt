# ============================================================================
# TROUBLESHOOTING
# ============================================================================

# Common Issues:

# 1. "Cannot find module" errors:
#    Solution: Delete node_modules and package-lock.json, run npm install

# 2. TypeScript compilation errors:
#    Solution: Check tsconfig.json configuration, update @types packages

# 3. Vite build failures:
#    Solution: Clear Vite cache with 'npx vite --force', check file imports

# 4. Tailwind CSS not working:
#    Solution: Verify @import 'tailwindcss' in index.css, check plugin config

# 5. Memory issues during development:
#    Solution: Increase Node.js memory limit: node --max-old-space-size=4096
